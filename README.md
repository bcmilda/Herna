# 🎮 Herna

Sbírka 54 her v jediném souboru `index.html`. Hraje se na mobilu (dotyk) i na PC (klávesnice). Funguje i bez internetu.

Každá hra má pravidla, úrovně nebo postup a tabulku rekordů. Kde to dává smysl, hraješ proti robotům.

## Jak hrát
- **Na webu:** přes GitHub Pages (Settings → Pages → Deploy from a branch → `main`).
- **Offline:** stáhni `index.html` a otevři ho v prohlížeči.

## Novinky
- 🏎️ **Turbo ulice**: pseudo-3D závody s kariérou, časovkou, policejní honičkou a garáží
- 🦸 **Aréna hrdinů**: hrdina proti hrdinovi, vojáci, věže a trůn
- ⚔️ **Válka pruhů**: obrana vlastního pruhu a posílání nepřátel soupeřům
- 🌀 **Bludišťová obrana**: stavíš bludiště z věží a kombinuješ živly
